# SplitMate 🛒 - אפליקציית התחשבנות קניות לדירת שותפים

אפליקציית ווב אינטראקטיבית בסגנון **טינדר (Tinder Swipe)** לחלוקה והתחשבנות מהירה והוגנת על קניות לדירה.

השותף מקבל קישור, רואה כל מוצר עם התמונה האמיתית שלו, שמו, מחירו המדויק מהקבלה, ומחליק:
* 💚 **החלקה ימינה / כפתור חצי:** משתתף חצי (50% מעלות הפריט)
* ❌ **החלקה שמאלה / כפתור דילוג:** לא משתתף (0%)
* 👑 **החלקה למעלה / כפתור מלא:** משלם מלא (100%)
* ↩️ **כפתור חזרה:** ביטול פעולה קודמת

בסיום, האפליקציה מחשבת במדויק כמה עלו כל הקניות וכמה בדיוק השותף צריך להעביר, עם פירוט מלא וכפתור לשליחת הודעת סיכום מעוצבת ב-**WhatsApp** בלחיצת כפתור!

## 🚀 איך להעלות ל-GitHub ולשלוח לשותף קישור חי (GitHub Pages)

האפליקציה בנויה ב-Pure Vanilla HTML5/CSS3/JS וללא תלויות שרת, ולכן מתאימה ב-100% לאירוח חינמי ב-**GitHub Pages**.

### שלב 1: יצירת מאגר ב-GitHub
1. היכנס ל-[github.com/new](https://github.com/new).
2. קרא למאגר בשם שתרצה (למשל: `roommate-bill-split` או `splitmate`).
3. בחר **Public** ולחץ **Create repository**.

### שלב 2: העלאת הקבצים מהמחשב (טרמינל)
פתח את הטרמינל בתיקיית הפרויקט והרץ:
```bash
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git branch -M main
git push -u origin main
```

*(הערה: התיקייה כבר מאותחלת ומחויבת כולה ב-Git!)*

### שלב 3: הפעלת GitHub Pages
1. בדף המאגר ב-GitHub, לחץ על **Settings** (הגדרות).
2. בתפריט הצדדי משמאל, בחר ב-**Pages**.
3. תחת **Build and deployment** -> **Branch**:
   * בחר בענף `main`
   * בחר בתיקיית `/ (root)`
   * לחץ **Save**.
4. תוך כדקה תקבל כתובת חיה לאתר:
   `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`

**זהו! שלח את הקישור לשותף שלך בווטסאפ שיוכל להחליק על המוצרים מהטלפון.** 📱✨
